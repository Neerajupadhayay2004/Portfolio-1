## Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Neerajupadhayay2004/Portfolio-1.git
cd Portfolio-1
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` file with the variables required by the project, including the Supabase configuration used by the AI assistant and project data integrations.

**Never commit real API keys or secrets.**

### 4. Start development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```

### 6. Preview production build

```bash
npm run preview
```

### 7. Lint the project

```bash
npm run lint
```
